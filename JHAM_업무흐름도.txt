  주요 업무 규칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 데이터 격리
     - 모든 데이터는 company_id 기준으로 격리 (다른 회사 데이터 접근 불가)

  2. 소프트 삭제
     - 자산 / 부서 / 팀 / 점검이력 / 템플릿은 deleted_at 으로 삭제 처리
     - 실제 DB 행은 남아있으며 조회 시 deleted_at IS NULL 조건 적용

  3. 외부 ID
     - API 는 항상 UUID(pid) 사용, 내부 정수 PK 는 외부에 노출하지 않음

  4. 식별번호 고유성
     - serial_number 는 전체 시스템에서 고유 (UNIQUE 제약)
     - 엑셀 업로드 시 중복 식별번호는 오류 처리

  5. 커스텀 필드 자동 생성
     - 엑셀 업로드 시 식별번호 뒤 컬럼은 해당 대분류의 커스텀 필드로 자동 생성
